# Concept identifier fixture

An authorized contract edit has ungrouped interface prose. The same meaning
appears in matching expands and an imported public concept. A direct consumer
uses a similar name that is not accessible through imports.

Expected behavior:

- Inspect meaning, local occurrences, matching expands and accessible imports.
- Reuse the matching public identity; treat inaccessible consumer terms only as
  naming evidence. Create local concepts only for materially distinct meanings.
- Check grammar, case-insensitive uniqueness, visibility and import ambiguity.
- Write scoped authorized grouping changes; do not require a removed evaluator
  stage before authoring. Validate and refresh affected native Design evidence.
- Any proposal-only analysis is advisory, not user authority or semantic proof.
